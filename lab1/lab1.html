Лабораторная работа №1

Основные понятия HTML

Задания

  1. В домашнем каталоге создать рабочую директорию public_html с правами доступа 755. Все выполненные задания должны находится в этом каталоге.
  2. Откройте текстовый редактор и создайте текстовый документ, содержащий следующий текст:
    # Настройки сервера Apache
    Options +Indexes
    DirectoryIndex index.html
    AddDefaultCharset utf-8
  3. Сохраните файл под именем .htaccess в каталог public_html.
  4. В директории public_html создайте каталог lab1
  5. В директории lab1 на основе шаблона lab1_1.txt создать документ lab1_1.html
  6. Запустите браузер и в адресной строке браузера наберите www.center.ogu/~логин/
  7. Убедитесь, что в браузер загрузилось содержимое директории public_html
  8. На основе файла lab1_2.txt создать документ html со внутренней навигацией.
  9. Связать между собой гиперссылками документы из архива lab1_3.zip.
  10. В каталоге public_html создать отдельные директории для каждой лабораторной работы (например: lab1, lab2 и т.д.). В созданные директории переместить файлы, относящиеся к соответствующим лабораторным работам. В каталоге public_html разместить файл index.html, содержащий гиперссылки на выполненые задания.
  11. На основе файла lab1_4.txt создать документ html, в котором необходимо проиллюстрировать атрибуты элемента img c помощью вставки изображений из архива images.zip. Создать подписи к изображениям.
  12. На основе примера lab1_5.html создать документ html, содержащий изображение с разными элементами которого связаны ссылки на выполненые выше задания.
  13. Проверить код на валидность с помощью плагина Html Validator. В качестве браузера рекомендуется использовать браузер Firefox Developer Edition.
  14. Создайте аккаунт на бесплатном хостинге СПРИНТХОСТ.
  15. Разместите выполненые задания на этом хостинге и пришлите на e-mail informatiki.kafedra@gmail.com ссылку на ваш сайт с указанием полного ФИО и группы.
  16. Для удобной работы с хостингом можно использовать ftp-клиент, например WinSCP. Также изучите возможности настройки хостинга с помощью файла .htaccess.
  17. Доступна версия этого сайта на бесплатном хостинге.
Внимание!

При создании документов используйте доктайп <!DOCTYPE html>.
